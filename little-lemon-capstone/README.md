# Little Lemon Capstone

Little Lemon Capstone is a React web application developed as part of the Meta Front-End Developer Capstone project.

The application represents the website of the fictional Little Lemon Mediterranean restaurant and includes a complete table reservation flow.

## Features

- Responsive restaurant website
- Home page
- About section
- Weekly specials section
- Customer testimonials
- Navigation between pages
- Table reservation form
- Reservation date selection
- Available time slots
- Number of guests selection
- Occasion selection
- Form validation
- Reservation confirmation page
- Responsive design for desktop and mobile devices

## Technologies Used

- React
- JavaScript
- HTML5
- CSS3
- React Router DOM
- React Hooks
- Create React App
